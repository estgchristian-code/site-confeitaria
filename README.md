# 🍰 Confeitaria Norske

> Site institucional e de encomendas para a **Confeitaria Norske**, desenvolvido com foco em acessibilidade e praticidade na experiência do usuário.

## 🔗 Link do Projeto
Acesse o site em produção: [norske-confeitaria.vercel.app](https://norske-confeitaria.vercel.app)

---

## 🚀 Sobre o Projeto
O projeto **Norske Confeitaria** é uma aplicação web voltada para a exibição de produtos artesanais (doces, bolos, salgados, bebidas e hambúrgueres), contando também com um painel administrativo integrado para gerenciamento.

---

## ✨ Funcionalidades
* **Catálogo de Produtos:** Seções organizadas para doces, salgados, bebidas e hambúrgueres.
* **Acessibilidade:** 
  * Botões de redimensionamento de fonte (`A-`, `A`, `A+`).
  * Modo de alto contraste / daltonismo.
* **Painel Administrativo:** Área restrita para administradores logados gerenciarem o conteúdo do site.
* **Integração com Firebase:** Uso do Firestore para persistência de dados e autenticação.

---

## 🛠️ Tecnologias Utilizadas
Este projeto foi desenvolvido utilizando as seguintes tecnologias:

* **HTML5 / CSS3 / JavaScript (ES6+)**
* **Firebase / Firestore** (Banco de dados e autenticação)
* **Vercel** (Hospedagem e Deploy Contínuo)
